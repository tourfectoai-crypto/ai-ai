# صفحة الإعدادات الاحترافية (/profile/settings)

## اللي اتغيّر
صفحة `/profile/settings` بقت صفحة واحدة كاملة بتابات:
- **👤 الملف الشخصي** — صورة شخصية (رفع/تغيير حقيقي) + الاسم + الشركة + الهاتف + كود الدولة
- **🔒 الأمان** — تغيير كلمة المرور
- **🔔 الإشعارات** — 3 تفضيلات حقيقية بتتحفظ في قاعدة البيانات (كانت وهمية قبل كده، مش بتتحفظ)
- **🔑 API** — عرض/نسخ/توليد مفتاح API جديد
- **🌐 اللغة والمنطقة** — زي ما كانت + قسم "حذف الحساب نهائيًا"

## بگ حقيقي اتصلح بالمرة: الصورة الشخصية
كان فيه كلاس `UploadManager` قديم بيرفع الصور في `storage/uploads/...`، لكن `storage/`
**برّه** `public_html` تمامًا (مش جزء من الـ web root)، يعني أي رابط صورة كان هيرجع 404
مهما الرفع نجح. الحل: كلاس جديد `AvatarUploadHandler` بيخزّن الصور جوه
`public_html/uploads/avatars/` عشان الرابط يشتغل فعليًا، وبيصغّر الصورة تلقائيًا لو
GD متاحة على السيرفر.

## الملفات
- **`app/Services/AvatarUploadHandler.php`** (جديد) — رفع وتصغير الصورة الشخصية
- **`app/Controllers/UserController.php`** (استبدال كامل) — الصفحة بالتابات + endpoint الرفع
- **`app/Controllers/SettingsController.php`** (استبدال كامل) — تفعيل حفظ الإشعارات فعليًا
- **`app/Models/User.php`** (استبدال كامل) — إضافة `avatar_url` وأعمدة الإشعارات لـ fillable
- **`app/routes/api.php`** (استبدال كامل) — route جديد `/api/user/avatar`
- **الـ migration** — أعمدة جديدة في `users`: `avatar_url`, `notify_email`, `notify_chat`, `notify_reviews`

## خطوات الرفع
1. شغّل الـ migration في phpMyAdmin الأول (قبل رفع الكود، عشان الأعمدة تكون موجودة).
2. ارفع الملفات كلها (كل الملفات دي مش كلاسات جديدة إلا `AvatarUploadHandler.php`).
3. لـ `AvatarUploadHandler.php` بس، ضيف في `public_html/index.php` تحت أسطر الـ require_once القديمة:
   ```php
   require_once APP_PATH . '/Services/AvatarUploadHandler.php';
   ```
   (لو بتستخدم نسخة الـ index.php اللي فيها الـ loop بتاع `$optionalNewClassFiles`، تقدر تضيفه في نفس المصفوفة بدل سطر منفصل.)
4. تأكد إن مجلد `public_html/uploads` قابل للكتابة (الكود بيحاول يعمله تلقائي بصلاحية 0755، لو السيرفر رفض، اعمله يدوي من File Manager وحط صلاحياته 755).
5. جرّب `/profile/settings` وارفع صورة تجريبية.
