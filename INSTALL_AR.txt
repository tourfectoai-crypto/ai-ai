إصلاح قائمة مهام مركز الشركة

هذه الحزمة تكمل حزمة فحص المنافسين السابقة.
خذ نسخة احتياطية ثم استبدل الملفين بنفس المسارات، وامسح كاش الموقع وCDN. لا SQL جديد.

السلوك:
- لا تظهر مهام خطط بدون هوية مؤكدة أو بخاصية موقع/إصدار ملف شركة مختلف.
- مطابقة البيانات المؤكدة تمنع ظهور مهام مبنية على بيانات تغيرت.
- الخطط القديمة تبقى في السجل مع علامة «سجل قديم — يلزم خطة جديدة»؛ لا حذف للخطط ولا تراجع عن تعديلات منشورة.
- زر فحص المنافسين وحقول بيانات الشركة باقية.

التحقق المحلي: JavaScript syntax، mocks تحميل الملف وحفظه وفحص المنافسين ناجحة. PHP فحص لغوي فقط، لا runtime lint أو اختبار قاعدة بيانات. لم يُرفع الإصلاح إلى الموقع الحي.

بعد الرفع: افتح مركز الشركة؛ بيانات الشركة القديمة غير المؤكدة تعطي قائمة مهام حالية فارغة. سجل الخطط القديم يبقى مع العلامة. بعد حفظ ملف الشركة وإعداد SEO وإنشاء خطة جديدة، يظهر ما يحتاج تدخلك من الخطة الحالية.
