# التحليل التنافسي — Website Builder (Tourfecto) — 2026-08-29

مقارنة منهجية لموديول "منشئ المواقع" (Website Builder) داخل منصة Tourfecto —
وهو موديول PHP مدمج (بدون Namespaces، PDO مباشر، بدون Composer) يولّد مواقع
سياحية متعددة الصفحات بالذكاء الاصطناعي — ضد أبرز منشئي المواقع العالميين
(Wix, Squarespace, GoDaddy Website Builder) وضد المنشئين المعتمدين على
الذكاء الاصطناعي (Durable, 10Web AI Website Builder)، مع مراعاة خاصة لسوق
المنطقة العربية (RTL، WhatsApp-first، النشاط السياحي ووكالات السفر).

> **القيد المنهجي:** التحليل معتمد على مخزون الميزات الفعلي للموديول
> (تم مسحه من الكود: Controllers/Services/Models/Migrations/Routes) مقابل
> المعرفة العامة الموثّقة للمنافسين. لا تُنسب للموديول أي ميزة غير موجودة
> فعليًا في الكود، وكل ادعاء مرفق باسم الملف الدال عليه. الميزات المعتمدة
> على LLM (Gemini) والمحفظة تُوصف كـ"جزئي/محدود" لأنها مقيدة برصيد
> pay-per-use وليس لامحدودة.

## 4. الميزة التنافسية الطبيعية للموديول (لا يملكها المنافسون العامون)

- **حجز سياحي حقيقي مدمج، لا مجرد صفحة**: كل رحلة/غرفة تُزامن مع `crm_products`
  وتُحجز عبر `BookingEngine::createBooking` مع إدارة توفر (`InventoryService`)،
  دفع Stripe إن وُجد، وإسناد حجوزات من إعلانات Meta/Google عبر
  `AdTrackingService` — منشئو المواقع العامة لا يوفرون محرك حجز جاهزًا عميقًا
  كهذا بدون مكوّنات إضافية.
- **مولّد AI متخصص في النشاط السياحي بمعرفة المجال**: الشات يجمع بيانات
  (عناصر، تواصل) ثم يولّد **برنامج يوم بيوم** للرحلات أو غرف/أجنحة كاملة
  للفنادق بلغة العميل (ar/en/fr/de) مع RTL صحيح — Wix ADI وDurable يولّدان
  مواقع عامة، لا محتوى سياحي تفصيلي.
- **حلقة تقييمات + طلبات تواصل داخل المنصة نفسها**: جمع التقييمات مع
  تحكّم بالنشر (اعتماد/رفض) وطلبات حجز بحالات، كلها تُدار من لوحة تحكم
  مستقلة لكل موقع — تكامل يشبه TripAdvisor داخل نفس منصة التشغيل.
- **SEO تلقائي بمسؤولية محاسبة (Auto-Pilot)**: Website Optimizer يكتشف
  المواقع المولّدة (بالـslug أو الدومين المخصص) ويطبّق إصلاحات
  `seo_title`/`seo_description` تلقائيًا مع سجل تغييرات وRollback حقيقي
  (`auto_pilot_change_log`) — ميزة لا يقدمها منشئو المواقع العامة بهذا الشكل.
- **WhatsApp-first**: CTA "احجز الآن"/"تواصل عبر واتساب" في كل صفحة مع
  رسائل حجز جاهزة، بما يناسب سوق المنطقة العربية.
- **بدون تبعيات خارجية**: يعمل بالكامل داخل PHP/PDO الحالي بدون Composer،
  قابل للتشغيل في البيئة الحالية فورًا.
