# خارطة التنفيذ — Tourfecto OTA Hub

## النطاق الوظيفي المستهدف

1. **مركز الاتصالات:** حسابات متعددة لكل عميل/منشأة، حالة اتصال وصلاحيات لكل قدرة، انتهاء التوكن، فصل بيانات العملاء، وسجل تدقيق.
2. **الحجوزات:** استقبال إنشاء/تعديل/إلغاء، معرف خارجي ثابت، مطابقة المنشأة والوحدة والسعر، اكتشاف التكرار، reconciliation queue، وإشعارات داخلية.
3. **التوافر والأسعار:** مخزون موحد للوحدات/الرحلات، mapping لكل channel، قيود الأسعار وسياسات الإلغاء، ومزامنة outbound بعد مراجعة تضارب المخزون.
4. **الرسائل:** Inbox موحد بمعرف المحادثة والرسالة، ربط الحجز، حفظ حالة الإرسال، مسودات وموافقة قبل الإرسال، وfallback لرابط Extranet عند غياب API.
5. **التقييمات:** مزامنة ما تسمح به المنصة، تطبيع المقياس (5/10)، منع تكرار التقييم، اقتراح رد AI مع موافقة، وإرسال الرد فقط عند `can_reply=true` وصلاحية موثقة.
6. **محتوى القوائم:** تدقيق العنوان والوصف والصور والمرافق والسياسات والتطابق بين القنوات؛ اقتراحات أولًا ثم تحديث آمن فقط عبر API مدعوم.
7. **التقارير:** إيرادات حسب المصدر، عمولات وإلغاءات، سرعة الرد، متوسط التقييم، أخطاء المزامنة ومعدل النجاح.

## ترتيب موصى به

- المرحلة A: اكتشاف schema والكود الحالي، توثيق جداول الحجز/المراجعات والصلاحيات، اختبارات رجعية.
- المرحلة B: تشغيل بنية الاتصالات والـ queue والسجلات مع dry-run فقط.
- المرحلة C: تفعيل مزامنة قراءة الحجوزات من مزود واحد على sandbox، ثم staging، ثم منشأة beta.
- المرحلة D: مزامنة التعديل والإلغاء والتوافر بعد اختبار idempotency والتزامن والحجوزات المتعارضة.
- المرحلة E: Inbox والتقييمات؛ موافقة بشرية افتراضية قبل أي إرسال خارجي.
- المرحلة F: تدقيق المحتوى وتقارير الأداء، ثم مزودون إضافيون حسب الموافقات.

## مصفوفة قبول لكل مزود

- موافقة تجارية وحساب developer/partner فعلي.
- صلاحيات موثقة لكل endpoint، وتجديد token آمن.
- اختبار sandbox/fixture لكل إنشاء وتعديل وإلغاء وفشل شبكة وحد معدل.
- deduplication على webhook وإعادة المحاولة مع backoff.
- mapping واضح للمنشأة والوحدة/الرحلة والعملة والمنطقة الزمنية وسياسات الإلغاء.
- سجلات لا تكشف token أو بيانات دفع أو بيانات ضيف غير لازمة.
- زر إيقاف اتصال، dry-run، وميزة rollback/مراجعة قبل أي كتابة جماعية.

## المنصات المستهدفة حسب الفئة

- إقامة: Booking.com، Expedia Group، Agoda، Airbnb، Vrbo، Trip.com.
- أنشطة: Viator، GetYourGuide، Klook، Civitatis، Tiqets، Musement، Headout.
- قنوات وسيطة/PMS: SiteMinder، Cloudbeds، D-EDGE، ومزودون آخرون يختارهم العميل.
- سمعة: Google Business Profile، Tripadvisor، ومراجعات القنوات التي تمنح صلاحية قراءة/رد.

هذه قائمة تخطيط وليست إثبات دعم API لكل وظيفة. لكل مزود تُسجل القدرات المعتمدة في الاتصال نفسه، ولا تُستنتج صلاحية الكتابة من صلاحية القراءة.
