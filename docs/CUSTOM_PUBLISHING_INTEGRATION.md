# استقبال مقالات Tourfecto على أي موقع (حتى لو برمجة خاصة)

الدليل ده لمبرمج موقع العميل. الهدف: تعمل نقطة استقبال (endpoint) واحدة بسيطة
في السيرفر بتاعك، وتورفكتو هتبعتلها المقال جاهز كل ما العميل يدوس "نشر".

## 1) اعمل endpoint واحد يستقبل POST

مثال (أي لغة برمجة - هنا مثال بسيط بـ PHP):

```php
// POST /tourfecto-publish  (أو أي مسار تختاره)

// 1. تحقق من التوكن السري (اختياري لكن يُنصح بيه بشدة)
$secret = $_SERVER['HTTP_X_TOURFECTO_SECRET'] ?? '';
if ($secret !== 'التوكن اللي هتحطه في تورفكتو') {
    http_response_code(401);
    exit;
}

// 2. اقرأ بيانات المقال
$data = json_decode(file_get_contents('php://input'), true);

// 3. لو ده مجرد اختبار ربط، رجّع نجاح من غير ما تنشر حاجة فعليًا
if (!empty($data['is_test'])) {
    http_response_code(200);
    echo json_encode(['success' => true]);
    exit;
}

// 4. انشر المقال في نظامك (قاعدة بياناتك / ملفات الموقع / إلخ)
//    $data['title'], $data['content_html'], $data['meta_description'], $data['slug']...

// 5. رجّع رابط المقال المنشور (اختياري لكن مفيد يظهر لعميلك في تورفكتو)
http_response_code(200);
echo json_encode(['success' => true, 'url' => 'https://clientsite.com/blog/' . $data['slug']]);
```

## 2) شكل البيانات اللي هتوصلك (JSON)

```json
{
  "article_id": 24,
  "title": "أفضل 10 أماكن سياحية في الأقصر",
  "content_html": "<h2>...</h2><p>...</p>",
  "content_markdown": "## ...\n\n...",
  "meta_description": "وصف قصير للمقال لمحركات البحث",
  "slug": "افضل-10-اماكن-سياحية-في-الاقصر",
  "suggested_keywords": ["كلمة1", "كلمة2"],
  "is_test": false,
  "source": "tourfecto"
}
```

## 3) الحماية (مهم)

كل طلب بييجي منّا فيه:
- Header: `Authorization: Bearer <التوكن السري اللي حطيته في تورفكتو>`
- Header: `X-Tourfecto-Secret: <نفس التوكن>` (بديل لو أسهل عليك تقرأه)

اتأكد من التوكن ده قبل ما تنشر أي حاجة، عشان محدش تاني يقدر يبعتلك مقالات وهمية.

## 4) الرد المتوقع منك

- **HTTP 200 أو 201** = نجح الاستقبال.
- أي كود تاني (400/401/403/500...) = تورفكتو هتعتبرها فشل وتوريه للعميل.
- لو رجّعت `{"url": "..."}` في الرد، تورفكتو هتحفظ الرابط ده وتوريه للعميل كـ "افتح المقال المنشور".

## 5) إعادة النشر / التحديث

لو نفس `article_id` وصلك تاني (العميل عمل "إعادة نشر" بعد تعديل)، المفروض تحدّث نفس
المقال بدل ما تنشئ نسخة جديدة - استخدم `article_id` كمفتاح للتعرف عليه في نظامك.
